# surrogate_harm_share

A self-contained, **calibrated** simulation study of the **surrogate-induced harm share**

```
theta = Pr( tau_S(X) >= 0 , tau_Y(X) <= 0 )
```

— the population share treated by a short-run-optimal rule `1{tau_S>=0}` who are actually
**harmed in the long run** (`tau_Y < 0`). This is a **double-threshold value functional** and a
second worked example for Zhenxiao Chen's JMP, *"Inference on Policy Value under
Admissibility-Constrained Optimal Treatment Rules"* (companion to `../dynamic_path_welfare`).

See [`docs/design.md`](docs/design.md) for the full design and [`docs/results.md`](docs/results.md)
for the numbers (generated by the run).

## What it demonstrates

- **Two decision boundaries** `M_S={tau_S=0}`, `M_Y={tau_Y=0}` meeting at a **codimension-2
  corner**, versus the single boundary of the ordinary treat-share `Pr(tau_S>=0)`.
- The **two-boundary moving-boundary derivative** `Dtheta = ∫_{M_S} - ∫_{M_Y}`, verified analytic
  vs finite-difference.
- **Irregularity**: `theta` has no √n influence function (Chen & Gao 2026 thin-set rate), unlike
  the **regular companion** `W_Y = E[max(tau_Y,0)]` (envelope cancellation). Same DGP, same samples.
- A **new two-band sieve-Riesz variance** (this project's extension of CCG's single-threshold
  `SieveVariance`), validated by Monte Carlo, plus a full-refit bootstrap.

## Calibration

Both calibrations are fit to the **Banerjee et al. (2015) graduation RCT** (`graduation.rda`
from Chen & Ritzwoller's `longterm` package): `S` = 2-yr consumption, `Y` = 3-yr consumption, with
the generative cascade `X -> (S(0),S(1)) -> (Y(0),Y(1))` of CR's App. D.2/D.3.

1. **Primary (exact-truth) oracle** — smooth kernel-ridge conditional means + residual resampling in
   place of the WGANs, so the **population truth is closed-form and exact** (the GAN only affects
   conditional *shape*, not the estimand). See [`docs/calibration.md`](docs/calibration.md).
2. **Second (truthful WGAN) calibration** — actually **trains CR's three cascaded Wasserstein GANs**
   (a faithful vendored `ds-wgan`: one-sided gradient penalty, output clamping, CR's tuning table) on
   CR's **full 20-covariate baseline set**, with GAN2 generating CR's **full 21-dim two-year surrogate
   vector** `S | X, W` and GAN3 forecasting `Y | S(full), X, W` — conditioning the long-run forecast on
   *all* surrogates, as CR do (a single surrogate is not a sufficient statistic). Validated CR-style:
   real-vs-generated means/variances/correlations line up across the 22 covariate+S+Y variables (corr
   match 0.046) and the 21-surrogate vector (0.091); the full surrogate recovers ATE_Y ≈ +6.7 (data
   +6.0). One honest consequence: the richer forecast flattens the short-run CATE so `τ_S ≥ 0`
   everywhere (the M_S boundary goes inert, θ = Pr(τ_Y<0) = 0.126); the codimension-2 two-boundary
   geometry is exhibited by the exact-truth primary calibration. See
   [`docs/wgan_calibration.md`](docs/wgan_calibration.md).

## Run

```bash
# primary (exact-truth) calibration
PYTHONPATH=src python run_study.py       # truth, geometry, derivative check, MC, rate, bootstrap
PYTHONPATH=src python make_figures.py    # figures -> results/figures
PYTHONPATH=src python write_results.py   # docs/results.md from results/logs

# second (truthful WGAN) calibration
PYTHONPATH=src python train_wgan.py       # train + cache the 3-GAN cascade, fidelity diagnostics
PYTHONPATH=src python make_wgan_figures.py # CR-style validation: real vs generated moments/histograms
PYTHONPATH=src python run_wgan_study.py   # WGAN population truth + MC coverage + rate + bootstrap

# sieve-DML inference (ML nuisances + two-band Riesz debiasing for the double threshold)
PYTHONPATH=src python run_dml_study.py    # coverage: sieve/RF/GBR nuisance x KRR/WGAN DGP -> docs/sieve_dml.md

# quadratic (corner-aware) debiasing + doubly debiased estimator (see docs/quadratic_debias.md)
PYTHONPATH=src python train_wgan.py --2d --scalar   # rough-truth DGP: scalar cascade, both margins bind
PYTHONPATH=src python run_debias_study.py           # 6 estimators x 3 DGPs x n-grid, 500 reps
PYTHONPATH=src python run_debias_study.py --wgan-scalar  # append the rough-truth WGAN arm
PYTHONPATH=src python run_corner_anatomy.py         # E[dg*dh] at the exact corner points vs theory
PYTHONPATH=src python write_debias_results.py       # -> results/tables/debias_table.tex, docs/debias_results.md
PYTHONPATH=src python make_debias_figures.py        # -> results/figures/fig_debias_*.png

PYTHONPATH=src python -m pytest tests -q  # property tests (test_wgan.py, test_dml.py, test_quadratic.py)
```

## Layout

```
src/harm_share/
  calibration.py       # primary oracle: KRR CATE surfaces, density, cascade sampler (exact truth)
  wgan_backend.py      # faithful vendored ds-wgan (WGAN-GP) + NumPy generator export
  wgan_calibration.py  # second calibration: 3-GAN cascade oracle, CRN truth, GPU precompute
  functionals.py       # population truth (MC + grid), geometry, two-boundary derivative + FD check
  estimator.py         # sieve plug-in (reuses opttreat), two-band sieve-Riesz SE, bootstrap, companion
  simulation.py        # Monte Carlo driver, rate experiment, bootstrap coverage
  sieve_dml.py         # cross-fit (sieve-)DML: ML nuisances + two-band Riesz variance
  quadratic.py         # SS quadratic (corner-aware) debiasing + doubly debiased (DML+quad) estimator
docs/design.md, docs/results.md, docs/calibration.md, docs/wgan_calibration.md,
docs/sieve_dml.md, docs/quadratic_debias.md
run_study.py, make_figures.py, write_results.py          # primary calibration
train_wgan.py, run_wgan_study.py                          # second (WGAN) calibration
run_debias_study.py, run_corner_anatomy.py, write_debias_results.py, make_debias_figures.py
```

## Dependencies

`numpy scipy pandas scikit-learn matplotlib joblib pyreadr`, and the CCG `opttreat` package
(imported from `../longterm-main/Optimal-Treatment-main`). The **second (WGAN) calibration** also
needs `torch` (a CUDA GPU is used automatically for training and the population precompute when
available, else CPU); the primary calibration does not need it.
